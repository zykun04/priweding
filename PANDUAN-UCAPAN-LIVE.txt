PANDUAN UCAPAN LIVE

Konfigurasi API Key dan URL Realtime Database sudah ada di firebase-config.js.

Untuk menerapkan aturan database dari folder ini:
1. Pastikan Node.js dan npm tersedia di Windows.
2. Buka terminal di folder undangan.
3. Jalankan: npm install -g firebase-tools
4. Jalankan: firebase login
5. Jalankan: firebase deploy --only database

firebase.json dan .firebaserc sudah disiapkan untuk mengirim aturan database saja. Tidak perlu menjalankan firebase init atau deploy Firebase Hosting; halaman undangan tetap di GitHub Pages.

Di Firebase Console, pastikan Authentication > Sign-in method > Anonymous sudah diaktifkan. File firebase-database-rules.json berisi aturan akses buku ucapan.
